# how does it work:
it uses googles mediapipe to track the landmarks (lets just call it points) on your face, and detects what your face looks like based of that
then it make server and a tunnel because like when you directly use the server without a tunnel it would work in roblox studio but when published wont work cuz roblox will search its own servers and everything will be messed up

# how use
down load the latest release (if you havent already)







press the exe file you just downloaded (it will take a while the first time for some stupid reason)

then go to a game that supports this repository (since createwebstreamclient is not on live games yet youll have to use [this](https://create.roblox.com/store/asset/109657620552137/Better-Dynamic-Faces) in roblox studio)

put in your given url into url bar, press begin, and done hooray (later on some games might use different ui so uhh thats not gud)
